## Результаты

В исходной матрице 10 источников × 4 среды: DNS успешен в 40/40, TCP — 33/40. Семь проверок не дошли до TLS: Nordwind 4 и ЕКП 3. TLS успешно проверен в 29 случаях, ещё 4 — просроченный сертификат Loyals.

- **ЕКП:** один Ubuntu runner получил реальный каталог и обычные ответы `/api/portal/loyalty/partners`, `/regions`, `/categories/partners`; остальные 3 VM завершились TCP timeout при том же адресе 37.230.144.130. Сам факт получения данных из стандартного GitHub доказан. Полные условия конкретных карточек и пагинация не сертифицированы; основной источник пока `probe`, а не реализованный адаптер.
- **Nordwind:** DNS работает, TCP 443 не отвечает во всех 4 GitHub VM. Это сетевой этап, не ошибка DOM-парсера.
- **CoralBonus:** 403 на robots и четырёх реальных URL в матрице. Карточка МЕДСИ остаётся 403 при обычном Playwright User-Agent в отдельном парном тесте.
- **РЖД Бонус:** DNS/TCP/TLS исправны; robots и целевая главная страница возвращают 403. Обычный Playwright User-Agent не устраняет отказ.
- **Аэрофлот:** DNS/TCP/TLS исправны; вместо robots возвращён HTML с ограничением владельцем сайта, хотя HTTP-код 200. Это не корректные правила обхода и не каталог. Внешний RU-тест для этого источника не выполнялся.
- **Loyals:** TCP исправен; сертификат истёк **30.04.2026 11:05:51 UTC**. Четыре среды получили ошибку проверки сертификата; OpenSSL отдельно подтвердил дату. Проверка TLS не отключалась.
- **МЕДСИ:** точная страница «Аэрофлот Бонус» открылась в 4/4 средах. Прежний сбой не воспроизведён; его точная причина не установлена.
- **«Мир» / Deva-Dent:** в 4/4 средах получены правильная страница и публичный объект с `xml_id=db7f56ef-dd05-4b44-a103-21d5b1316d58`. Отсутствие ответа в предыдущем длинном сборе не воспроизведено; снятие акции или общий запрет доступа не подтверждены.
- **Старая страница Utair:** транспортный код 401 с обоими User-Agent; текст страницы упоминает HTTP 403. Эти значения нельзя смешивать. Ранее доступный официальный media-раздел — отдельная альтернатива.
- **S7 — исправленная интерпретация контроля:** исходная матрица использовала специальный исследовательский User-Agent и получала 403. На одной VM при неизменных браузере/URL и новых анонимных контекстах: исследовательский UA **403**, стандартный Playwright UA **200 с реальным текстом Flowwow**, снова исследовательский **403**. Это не регрессия существующего production-парсера и не запрет GitHub целиком.

## Независимое сравнение сетей

Globalping выбрал Москва/Timeweb/AS9123 и Амстердам/DELUXHOST/AS214677. После первого измерения последующие использовали тот же ID выбора узлов `29snBE6kOhbrf74ht000217mE`; страны, города, ASN и сети повторно сверены в результатах.

| HTTPS-цель | Москва | Амстердам |
|---|---|---|
| ЕКП: каталог | 200, TLS authorized | timeout до TCP |
| Nordwind: партнёры | 200, TLS authorized | timeout до TCP |
| Coral: конкретная карточка МЕДСИ | 200, TLS authorized | timeout до TCP |
| РЖД: главная страница | 200, TLS authorized | timeout до TCP |
| S7: Flowwow | 403, TLS authorized | timeout до TCP |
| example.com: нейтральный контроль | 200 | 200 |
| www.wikipedia.org: нейтральный контроль | 200 | 200 |

Следовательно, NL-узел не был полностью лишён интернет-доступа. Но это только одна пара сетей: страна, провайдер, маршрут и IP меняются одновременно; у NL-контролей также более высокий TCP latency. **Глобальная блокировка всех зарубежных IP не доказана**, а один успешный GitHub-прогон ЕКП ей противоречит. Российский сетевой выход — обоснованный кандидат для следующего полного браузерного теста, не гарантия готового парсинга.

HTTP-тела независимых измерений не сохранялись. Код 200 из РФ может быть страницей приложения либо служебной страницей; точные партнёры, условия, полнота каталога и работа Playwright из РФ ещё не подтверждены. Globalping — измерительная платформа, не наш управляемый сервер.

## Ошибки экспериментального инструмента, не сайтов

Пример `ru1` из документации Check-Host уже отсутствовал; выбор исправлен по живому списку. Первый запрос измерения затем получил 429, поэтому через Check-Host результатов нет. В первом Globalping-прогоне HTTP-заявка получила 400; исправлены отправка пустого необязательного query и чтение уже созданных измерений после ошибки. Финальный прогон получил 8/8 результатов без ошибки API.

Текстовые выдержки браузера ограничены 600 символами. Лексический флаг challenge не распознаёт каждую русскую формулировку; отказ Аэрофлота установлен по тексту и `robots=invalid_document`, а не одному флагу. Текущие артефакты не являются полными правилами предложений.

## Следующие acceptance gates

1. ЕКП: адаптер по наблюдаемому UI/API; точное соответствие ID/условий; исчерпание пагинации; несколько успешных независимых запусков.
2. Nordwind/Coral/РЖД: небольшой Playwright-тест каталога и двух карточек через подконтрольный российский выход до обещаний полного сбора и расходов на постоянную инфраструктуру.
3. МЕДСИ/«Мир»: воспроизвести редкий сбой исходного длинного прогона; не переносить всю систему из-за одного пропуска.
4. Loyals: корректный TLS endpoint. Для Аэрофлота — отдельный успешный доступ; результат других сайтов на него не переносить.

Все инструменты выполняли ограниченные публичные проверки без входа, CAPTCHA-решателей, постоянных ключей, платных прокси и отключения TLS. Google-токены, личные browser sessions и содержимое таблицы не передавались в артефакты или измерительные сервисы.
