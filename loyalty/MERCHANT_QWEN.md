# Модельный разбор: Qwen3.8 27B через Kilo

Выбранный обработчик в ветке PR #90 — `merchant_extract.py`, закреплённый `qwen/qwen3.8-27b:free`. Используется существующий `KILO_API_KEY`. Gemini и Ollama не являются fallback. Это переход модельного CLI в рабочей ветке, не merge и не подключение к ежедневному сборщику/Sheets.

## Запуск

```sh
python -m pip install -r loyalty/merchant-requirements.txt
# Проверить входы и сохранить запросы без сети и без ключа:
python loyalty/merchant_extract.py --manifest inputs/manifest.json --out prepared
# Выполнить; KILO_API_KEY задан через окружение или Actions Secret:
python loyalty/merchant_extract.py --manifest inputs/manifest.json --out results --execute
```

Вывод — только в новую директорию. Ключ не передаётся аргументом командной строки, в URL, промпте или файлах.

## Входной контракт не изменён

Манифест `{"documents": [...]}`; каждый элемент:

```json
{
  "id": "partner_program",
  "target": {"partner": "Партнёр", "program": "Программа", "as_of": "2026-10-04"},
  "text": "partner/visible-text.txt",
  "images": ["partner/page-1.png", "partner/page-2.png"],
  "sha256": {
    "partner/visible-text.txt": "<SHA256 байтов текста>",
    "partner/page-1.png": "<SHA256 PNG>",
    "partner/page-2.png": "<SHA256 PNG>"
  }
}
```

Все пути — внутри директории манифеста; хеши обязательны. Весь пакет проверяется до сети. Передаются все PNG в указанном порядке и весь текст; соседние программы не вырезаются. `as_of` — дата оценки, не конец акции. Дополнительные поля элемента сохраняются как происхождение входа, не как инструкции.

Пределы: 1–30 документов, 1–40 PNG на документ, текст до 500000 символов, исходные байты документа до 14 МБ, тело HTTP до 20 МБ. Превышение — ошибка, не усечение. Модуль принимает подготовленные PNG/текст: сам не ищет сайты, не делает OCR и не преобразует HTML/PDF.

## Модельный этап

Полный вход + TARGET + прежние `merchant_prompt.txt` и `merchant_offer.schema.json` → один модельный этап → JSON. Системный и пользовательский текст совпадают с прежним облачным опытом. Запросы на четырёх замороженных кейсах побайтно совпадают с успешным контролем Kilo/Qwen.

Параметры: `temperature=1`, `max_tokens=8192`, `reasoning={enabled:true, effort:high}`, `stream=false`. Схема присутствует в сообщении и `response_format.json_schema` (`strict=true`). Никаких `target_blocks`, второго LLM, специальных правил партнёра или исправления ответа.

Принимается только один завершённый `finish_reason=stop` ответ запрошенной модели (допустим возвращаемый alias без `:free`). Не принимаются tool calls, refusal, пустой/незавершённый ответ, Markdown вместо JSON, дубли JSON-ключей, бесконечные числа, нарушение схемы или противоречие `has_offer` и `offers`. Рассуждения не подменяют финальный ответ. `how_to_get` не переименовывается в публикуемые строки.

Сохраняются все PNG/текст, упорядоченные хеши, запрос без повторного base64, сырые ответы, метрики и неизменённый `extracted.json`. `schema_valid` не означает смысловую правильность: цитаты, принадлежность программе и полнота проверяются отдельно. Всегда `publication_allowed=false`, `semantic_review=pending`.

## Проверка бесплатного маршрута и ошибки

Перед первой генерацией — один публичный GET `/models`, без ключа. Точный ID должен встретиться один раз, иметь `isFree=true`, нулевые цены, изображения, reasoning и структурированный вывод. Иначе пакет блокируется без POST. Каталог и результат проверки сохраняются. Ошибки каталога автоматически не повторяются.

Временные 408/429/500/502/503/504: максимум три POST с одним телом; паузы 15/30 с + 0–3 с случайной добавки. `Retry-After` и стандартный RetryInfo — нижняя граница. Если ожидание больше 60 с или не укладывается в бюджет допуска 300 с, результат `deferred`, без обхода квот. Сетевые тайм-ауты имеют неизвестный исход и не повторяются; ошибки завершения/схемы и постоянные HTTP-ошибки тоже не повторяются. Это бюджет допуска попыток, не жёсткий таймер HTTP-потока; сокеты и Actions job имеют отдельные пределы.

После неуспеха пакет прекращается, хорошие ответы сохраняются, оставшиеся ID перечислены в `not_attempted`. Код выхода неполного пакета — 2. Ошибка API никогда не означает «предложения нет». Нет фоновой очереди, бесконечных повторов, покупки кредитов, переключения модели или публикации.

Ключ — только в `Authorization: Bearer`; redirects запрещены. Буквальное отражение ключа редактируется только для безопасного хранения и не принимается как результат. Если API явно сообщает ненулевой `usage.cost`, ответ сохраняется, но извлечение не принимается, пакет останавливается. Отсутствующая стоимость не выдумывается; фактический баланс отдельно не проверяется. Бесплатные маршруты могут разрешать обучение на запросах; данный процесс предназначен для публичных страниц, не приватных документов.

## Actions

`merchant-qwen-kilo.yml` заменяет текущий Gemini workflow. Регрессии запускаются по изменениям соответствующих файлов; живой тест — только `workflow_dispatch` или коммит с `[qwen-smoke]`. Тест использует текущий CLI: четыре замороженных документа, один GET каталога, не более 12 POST. Источники Actions временные; обычный CLI от их хранения не зависит. Секрет доступен только шагу инференса.

Результаты фиксируются после чтения завершённых артефактов. Успех четырёх знакомых примеров не доказывает стабильность бесплатного API или качество на незнакомых источниках.

Проверенные API-источники: https://kilo.ai/docs/gateway/api-reference и https://api.kilo.ai/api/gateway/models. История Gemini: `experiments/cloud_json/GEMINI_MIGRATION_RESULTS_20261003.md`; история облачного сравнения: `experiments/cloud_json/RESULTS_20261003.md`.
