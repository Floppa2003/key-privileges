## Настройки и поведение

- Все подготовленные PNG в исходном порядке + полный текст + TARGET + та же явная JSON Schema → один модельный этап → JSON.
- Температура 1, thinking HIGH, лимит вывода 8192; без `target_blocks`, дополнительной подсказки, обрезки входа, исправления JSON или второго LLM.
- До трёх HTTP-попыток на документ, только для 408/429/500/502/503/504. Тело запроса неизменно. Паузы 15/30 с плюс 0–3 с случайной добавки; серверный Retry-After/RetryInfo не сокращается.
- Длинное ожидание или исчерпание бюджета приводит к `deferred`. Неисправный JSON, другой returned model, незавершённая генерация, ошибки доступа и сетевой тайм-аут не запускают повторную генерацию.
- Пакет останавливается после неуспеха; готовые результаты сохраняются, оставшиеся документы перечисляются в `not_attempted`. Ошибка API не становится `has_offer=false`.

Полный контракт, ограничения размера, режим подготовки без сети и команды запуска находятся в `loyalty/MERCHANT_GEMINI.md`. Промпт и схема — самостоятельные файлы рядом с обработчиком. Новые зависимости объявлены и в отдельном списке запуска, и в общем списке для штатного обнаружения тестов.
