## Fixed arms and request budget

- Gemini native generateContent API: `gemini-3.8-flash`; reasoning HIGH, temperature 1, output cap 8192; MIME application/json + the unmodified JSON Schema. No `includeThoughts`; reasoning token usage, where returned, is diagnostic only.
- Kilo chat completions API: `minimax/minimax-m3:free`; reasoning enabled/high, temperature 1, output cap 8192; strict JSON Schema request. Preflight refuses a missing model, nonzero catalog price, or missing image/structured-output/reasoning support. Never substitute a paid or automatic model.

Each arm: three predetermined rounds of theatre, Nevsky, museum, bookshop (maximum 12 inference HTTP attempts). Exactly one call per sample, no retry or continuation. At least 15 seconds between completed requests. One metadata preflight GET per provider precedes inference. Any non-200 HTTP response or transport failure stops the remaining arm instead of retrying until success. Model-level incomplete/invalid answers remain failures; the rest of the predetermined samples may continue. No new samples selected after observing quality. A model-identity mismatch also stops the arm.

This changes model + serving stack + model-specific reasoning/sampling parameters together. Ollama-only options and penalties are not copied to different APIs. Tokenizers, native reasoning controls, image processing and hidden upstream prompts differ. Do not claim a perfectly isolated model-weights comparison or identical effective compute budget.

## Evaluation, set before outputs

Primary: completed final JSON, valid unchanged local schema, correct program, complete essential restrictions/acquisition instructions, no materially unsupported facts. Secondary: field precision, genuine verbatim evidence, unnecessary duplicates, advice falsely labeled inference, latency and native token usage. Green CI/schema alone is not semantic success.

- Theatre EKP: 10%; theatre-selected shows; present EKP at cashier; at most two tickets per show; no later than one day before; no stacking. No Mendeleev-card screenshot, FIO or ID-document condition. No invented expiry/promo/accrual date.
- Nevsky RZD Bonus: 500 points for every night, book on hotel's site, participant number in Comment, accrual within 45 days after checkout. Instructions in how_to_get, not only advice. No invented expiry/promo.
- Museum EKP: 10% entry ticket at cashier, no website/self-service-terminal purchase, no stacking. Distinguish a published instruction from reasonable optional advice.
- Bookshop EKP: do not invent numeric discount; preserve the actual published scope/list of book types and distinguish absent conditions from claims there are none. No invented dates/codes.

These four documents are familiar, not held out; three samples are not an estimate of catalog-wide reliability. Manual semantic review is by the same assistant, not blind. `semantic_review=pending` and `publication_allowed=false` in raw run metadata are not changed by automated checks.

## Security and artifacts

Only public frozen webpages go to providers. Keys exist only in the appropriate inference step's environment and authentication header, never request URLs or serialized payloads. TLS verified, redirects disabled, no environment proxies, no shell tracing. Provider responses/errors are defensively scrubbed for credential echoes before saving. No secret hash, partial key or length is logged. Secrets are not copied into model prompts. Source text is data, never executed.

Preserve exact code/commit/workflow, complete prompt/schema, original image bytes with ordered SHA256, native raw response, native model identity, finish reasons, usage, latency and failures. Saved request logs omit only image bytes, with ordered image hashes; exact UTF-8 HTTP body SHA256 is recorded. The real request includes all images. No hand-edited JSON replaces a raw model answer.

The user supplied keys for free-tier testing; this workflow does not enable billing or buy credits. Kilo's exact free price is checked at execution. Gemini's account billing tier is not exposed by model metadata, so the run cannot independently certify a paid-enabled project's final bill. Model/HTTP quotas or access errors are reported, not worked around.
