# Prompt-only paired experiment, frozen before inference, 2026-09-28

Question: does defining all existing fields and programme boundaries improve the current Qwen results?
Intervention: messages[0].content ONLY. Frozen 1024px PNG bytes, full text, user message, as_of=2026-09-27,
JSON schema, model digest, Ollama version and options unchanged. Six documents, twelve calls,
one old/new pair on the same runner, fresh model process per call. Order balanced 3 old-first / 3 new-first.
At most three concurrent CPU-only jobs. No retries. Gold facts are NEVER sent to the extractor.

Development cases: lavka, muzcomedy, nevsky, academia. Preservation controls: rzd_museum, golden_triangle.
All cases are familiar diagnostic fixtures; neither this comparison nor review is blind generalisation evidence.

Predeclared review dimensions per case: presence and amount/unit; audience; programme/object scope;
material restrictions; redemption and code delivery; date-role/accrual; internal consistency and unsupported additions.
Read dedicated fields, not merely evidence. Correct evidence does not repair incorrect fields. No exact-string grader
or rigid row-count requirement. Unknown-size discount is an offer; unknown code is not a literal code.

Required facts, fixed from existing source reviews:
- lavka: discount exists, value is unpublished/null, applies to listed books, audience EKP holders; no invented percent.
- muzcomedy: EKP 10%, theatre-selected performances, at most two tickets, at least one day before show,
  cashier/card, no stacking. Do not borrow Mendeleev-card identity screenshot requirements or general concession rows.
- nevsky: 500 RZD Bonus points per night; participant/account scope; website booking with RZD Bonus number
  in Comment; posting within 45 days AFTER checkout. Number is not promo code. Redemption is the user's action.
- academia: 15%, three named properties (Shuvalov, Teplov, Vasilievsky), base room-only/breakfast tariffs,
  site/reservation-office booking, code from EKP app not publicly printed. Properties must not exist only in evidence.
- rzd_museum: 10% entry ticket, EKP holders, cashier only, no website/self-service terminal or stacking,
  no invented code/expiry.
- golden_triangle: 15% standard breakfast tariff, RZD Bonus participants, official website, literal RZD;
  no adjacent EKP/GOLD offers or codes; no invented expiry.

Per field: pass / partial / fail / not_applicable, with explicit reasons. Case complete only if all material facts
are represented with correct scope and no material contradictions. Unknowns containing third-party offers are defects.
New prompt is an improvement candidate if it fixes at least one prior diagnostic defect without introducing
new critical errors or losing either preservation control. An overall production gate remains closed regardless
of the small-sample result. Report old/new case and field outcomes, timings, RAM and transport failures separately.
Do not revise prompt or labels after observing responses. A follow-up change requires a separately labelled experiment.
