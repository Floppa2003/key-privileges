not combined with other offers; website and self-service terminal purchases
excluded. Literal promo code and explicit validity period not stated. No extra

The booking-widget dates were not interpreted as offer expiry.

The JSON examples were produced by ChatGPT after reading these page images, not
by an independent or unattended model endpoint. Both satisfy the supplied local
schema; this is format validation, not an extraction-accuracy score. All examples
retain publication_allowed=false and undated status, and personal eligibility,
room availability and redemption were not tested. Two known examples do not
establish an improvement over text-only inference.

## Important PDF limitation discovered

The hotel's cookie banner sits over an unrelated card in the full screenshot,
but Chromium repeats/repositions it at the bottom of the PDF page, overlapping
part of the RZD card on page1. The screenshot shows that RZD card unobscured.
Therefore its JSON was checked against BOTH PDF and paired screenshot, with this
limitation explicitly recorded. No clean PDF-only success is claimed for the hotel.
RZD Museum's relevant paragraph is legible in PDF; its footer/banner is retained.

## Recommendation / next boundary

Keep native PDF AND screenshot rather than PDF alone. Inspect legibility before
inference; preserve source URLs, observation time and evidence-page references.
Use one short programme-specific JSON extraction prompt with null for unknown
values; do not reinstate merchant-specific CSS extraction. Closed/obscured sections
remain unresolved, not inferred.

Next unperformed step: send these exact PDFs/images to a separately controlled
vision model through a real inference endpoint and compare with text-only on the
same model. API transport/model choice/strict-output behavior remains unverified.
Do not report the in-conversation demonstration as that API experiment.
